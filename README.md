# @cowprotocol/app-data

AppData schema definitions

These schemas are used in the data encoded on `appData` field for CowProtocol orders.

For more details, check [the docs](https://docs.cow.fi/cow-sdk/order-meta-data-appdata).

## ⚠️ Deprecated ⚠️

This project has been migrated to the cow-sdk mono repo and can now be found under [the app-data package](https://github.com/cowprotocol/cow-sdk/tree/main/packages/app-data), and is published as [@cowprotocol/sdk-app-data](https://www.npmjs.com/package/@cowprotocol/sdk-app-data)
